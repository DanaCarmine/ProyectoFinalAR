# Proyecto Final: Aplicación de Realidad Aumentada para Visualización de Trajes
Proyecto desarrollado en Unity utilizando Vuforia Engine para implementar una aplicación móvil de realidad aumentada enfocada en la visualización y personalización interactiva de trajes formales en 3D.

# Autora
Hernández Rubio Dana Valeria - 317345153

# Descripción General
Este proyecto implementa una aplicación de realidad aumentada que permite visualizar y personalizar modelos de trajes formales mediante el uso de un dispositivo móvil y un Image Target.

La aplicación permite al usuario interactuar con distintos elementos del traje en tiempo real.

El sistema fue desarrollado utilizando Unity Engine, Vuforia Engine y programación en C#, integrando modelos 3D personalizados y recursos optimizados para dispositivos Android.

La propuesta está inspirada en necesidades reales del negocio de sastrería “Andro Trajes Sobre Medida”, buscando mejorar la experiencia de atención al cliente mediante herramientas visuales e interactivas durante el proceso de personalización de prendas.
